# V11.21 B5b：源级合成信号恢复校准

## 技术结论

完整源→响应→年度模型→目标→成本账户→独立审计链路，能够恢复本次预先固定的强合成机制。planted组的交互候选通过全部探索性筛选；同随机种子的null组两个候选均未通过。两个数据组全部完成，失败/成功账户均保留，未挑选随机种子或修改阈值。

**这不是市场Alpha。** 合成收益不能用于预计300万元真实资金回报。没有V11.21真实市场数值读取、新实证Trial或Court结论；历史债务仍3660。当前只支持继续有界实证准备，不支持实盘或放宽门槛。

## 口径及模型实验

每组160只虚构股票，2022年1月3日至2024年12月31日共782个合成工作日，不是交易所交易日历。2022用于训练起点，2023–2024共522日连续账户；每组23项合成native预留、14个年度监督模型、28个跨成本绑定、22个账户。两组共46项合成预留，不计入实证债务。

种子184021在生成源文件前冻结。两组使用相同独立流量和收益噪声，planted额外让过去20日响应交互信号的平均值影响下一日收益，强度固定0.06；null关闭此项。响应归一化/拟合仅用严格过去60日。开盘为前收，下一开盘后才获得未来注入收益。源生成器不调用生产响应/预测/选股计算，oracle仅以单独摘要留证，未成为模型输入。

模型、20日持有期、四相位分层40股选择、缓冲、300万元、82/164bps、过去ADV容量与全部对照均不改。标准及双倍成本是既有冻结成本参数的两个账户，不是本次择优配置。独立审计复算源/历史特征/成熟标签/模型/目标和账户现金股票数值；保存单独AUDIT/ASSESSMENT，不覆盖原RESULT。

## 限制与后续决策

1. 这是单一固定种子、故意很强且与声明机制对齐的DGP恢复试验；不是统计power曲线、真实噪声强度测试或5%误报率估计。不能从1个null没有幸存者推断FPR很低。
2. 仍须确认市场规模内存余量，必要时减少重复物化。之后实现跨operation独占生产入口，绑定固定V11.20父RESULT/AUDIT/原生账本、源和旧卡/目标实际字节、代码及审计器与Issue184完整预登记。
3. 只有这些工作完成，才启动一次冻结2022–2024的23项实证预留；携带3660债务，不读2021数值warmup、2025/2026或新增仓库数据，不重新解释旧窗口为fresh OOS。
4. 有希望的真实候选先冻结再深度证伪；DSR≥0.95、PBO≤0.05、placebo≤0.05、全部历史Trial、路径/容量/成本/独立证据要求不变。券商整手/最低费用、first-seen和公司行为现金等限制仍需如实披露。

开放问题：在真实且更弱、状态变化的价格—流量关系下，新表示是否仍能提供超过全部对照的可交易增量？本报告没有回答，也不保证可用Alpha一定存在。
