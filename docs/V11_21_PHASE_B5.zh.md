本检查点补齐了从冻结源文件到模型、目标和账户的独立数值复算；合成完整流程通过初轮审计。它证明实现能够被另一条计算路径核对，不证明市场存在预测收益。V11.21 仍未运行真实市场实验，新实证 Trial 为 0，历史累计下限仍为 3660。PR #199 保持 Draft，未合并 main，包版本仍为 11.20.0。

最终完整回归 **1306 passed、1 skipped（417.96 秒）**，Ruff、14 个变动 Python 文件格式及 Git 空白检查通过。证据哈希见 `V11_21_VERIFICATION.md`。下述资源数据来自实际本机进程测量，不是市场回测。

## 口径：独立复算不等于独立样本

完整流程 fixture 使用 80 只合成股票、550 个工作日，覆盖 2022 年训练和连续 2023/2024 账户。488 份历史响应 bundle 含 39,040 次逐股拟合；监督模型实际有 14 份，跨成本原生绑定 28 条，账户 22 个，全部原生预留 23 项。这些临时测试账本不增加真实市场搜索债务。

“独立”指不调用生产的数值读取、响应估计、风险排名、监督拟合、标签、选择和执行函数来冒充复核。规范 SHA-256、原生拟合血缘和数据结构等基础设施仍共享，不是独立开发团队的第三方认证。来源首见时间的真实性、券商成交可行性及 Alpha Court 属于另一层证据。

## 源、模型和目标可以沿独立路径复算

- 独立 DuckDB 投影只读取 daily/fund_flow 两类文件的授权数值年份；验证实际源文件 SHA、行数、键唯一性、日期范围，按 2048 行分批读。其他三类源仅出现在 manifest 中，不打开其文件。
- 独立逐日参考实现核对全部 bar、风险分层排名和逐股历史响应参数；先处理当时可见性，再处理数值，保留缺失全局交易日、调整因子、停牌和保守开盘限制口径。
- 监督复算自行构造成熟配对标签、日期等权设计及固定乱序对照，通过增广加权 SVD 最小二乘求解，而非复用生产正规方程。逐项核对训练前缀、样本/设计 SHA、参数、梯度和两成本拟合绑定。
- 在模型系数独立核对后，使用原保存系数独立复算九种新策略的排名与四阶段缓冲目标，避免不同浮点解的末位误差改变并列排序。旧两种锚点按原卡和原目标实际字节验证。

浮点比较采用明确容差（一般相对 2e-10、绝对 2e-12）；身份、键、顺序和原始文件 SHA 不能靠容差放行。测试包含未来值毒化、缺口、不可用时间、拆股、零量、重复键和原生证据不一致。

## 账户不只核账，也核对下单意图

独立审计从昨日股份、现金、开盘价与目标重建请求金额，验证 target_changes 的待执行集合、容量限制及线性费用下的解析资金缩放。随后复核实际股份、现金、估值、每日收益、年度收益、夏普、减值/恢复事件及汇总数值。

完整账户报告按独占文件保存，并绑定原生结果 SHA。离线审计同时核对精简 JSONL 和完整报告，不执行新回测、不修改原 RESULT 或 Trial。完整流程测试验证审计前后 RESULT 和 SQLite 字节不变。

仍不独立认证订单原因文字标签及由这些标签参与定义的 blocked_orders 数量；报告对此显式标注，核心请求/成交/受阻金额均独立核对。开盘涨跌停仍是披露的日线代理、持仓仍允许分数股，不能当作真实券商交易认证。

## 320 股资源实测：能运行，但未证明全市场安全

独立进程生成两份合成源文件，每份 176,000 行（320 股 × 550 日），运行历史构建及已验证不可变缓存。它没有执行监督模型、22 个账户或完整离线审计。

| 完成阶段 | 累计耗时（秒） | 进程历史峰值 RSS（字节） | 当前 RSS（字节） |
|---|---:|---:|---:|
| 导入后起点 | 0.00 | 66,551,808 | 66,547,712 |
| 合成源生成 | 1.73 | 131,911,680 | 71,475,200 |
| 原生历史构建 | 189.71 | 536,477,696 | 205,410,304 |
| 缓存加载及校验 | 193.59 | 577,728,512 | 541,573,120 |

RSS 为驻留物理内存；MiB=2^20 字节。最终峰值约 550.96 MiB，私有提交峰值 631.51 MiB。机器总物理内存实测 31.92 GiB，末次采样可用 15.46 GiB，不代表未来运行仍有同样余量。历史 JSON 107,557,523 字节，bundle 合计 101,732,413 字节。

单个规模点不能建立线性内存/耗时模型。源参考扫描有分批上限，但历史 JSON、不可变缓存、训练设计和目标/账户仍需评估全流程峰值；不能将分批源扫描称为整条管线已实现有界内存。原 manifest 总行数含未授权读取数值的 2021 年，不是本轮 2022–2024 实际选中行数。

资源工具首次直接启动因导入旧安装目录而在源生成前失败，已改为明确使用本工作树 src；随后上述独占 probe 成功。没有重复消费市场预算。

## 后续顺序：先证明机制可恢复，再进行一次受控实证

1. 补齐源文件级 planted/null：从可知生成机制构造原始合成价格和资金流，验证完整流程能恢复预设关系，并不把空信号误报；仅有矩阵级测试和本轮数值一致性还不够。
2. 对历史/训练/完整审计做进一步资源测量，必要时改为有界持久化/顺序释放，避免全市场启动后内存失败。测量不是扩大市场搜索权限。
3. 完成绑定固定父 RESULT/AUDIT/账本、来源/原卡目标/代码/审计器 SHA、完整预算及 Issue #184 预登记的跨 operation 独占入口；独立 AUDIT 与后续 ASSESSMENT 追加保存，不改写旧 RESULT。
4. 以上验收通过并冻结后，才允许一次 2022–2024 实证操作完整预留 23 项，携带全部历史债务。保留 300 万、82/164 bps、所有对照和门槛；不读取 2021 数值 warmup 或 2025/2026。
5. 有希望的结果先冻结并深度证伪；失败保留证据并提出新的有限机制方案。不得在已揭示样本反复调参后称为独立验证。DSR≥0.95、PBO≤0.05、placebo≤0.05 及路径/独立证据要求不变。
