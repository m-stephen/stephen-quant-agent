# V4.5 候选级 2025 验证结果

## 最终结论

V4.4 候选在 2025 年明确失效，结论为 `REJECT_ALPHA_COURT`。它仍是一个有研究价值的
历史现象，但不再应被称为当前可靠 Alpha，更不能进入实盘。

| 指标 | 2025 结果 |
|---|---:|
| 完整组合超额收益 | -1.64% |
| 完整组合超额夏普 | -4.0858 |
| 相对匹配基准选股增量 | -1.38% |
| 路径夏普中位数 / 下四分位 | -1.0253 / -1.3620 |
| 盈利路径 | 6/20 |
| 最大回撤 | -2.08% |
| 正收益压力单元 | 0/27 |
| 2 倍 / 3 倍成本收益 | -2.50% / -3.36% |
| 2,000 万资金收益 | -1.64% |
| 信号 / 收益置换 p 值 | 0.040 / 0.065 |
| DSR | 0.000000 |

没有容量受限成交，说明失败不是资金规模造成的。事后诊断显示，`mixed` 状态平均
RankIC 从 2022 年 0.163、2023 年 0.079、2024 年 0.091，下降到 2025 年 0.024；2025
年第三季度选股增量约 -1.92%，是全年方向翻转的主要来源。这更像因子衰减或市场结构
变化，而不是交易成本误差。

## 后续建议与测试策略

1. 冻结并退役当前候选，不允许使用 2025 调整窗口、广度、方向或市场状态。
2. 将涨停持续性从独立 Alpha 改为风险/拥挤度特征，与筹码、资金流、竞价和融资融券
   等正交域组合；先验证增量信息，再讨论组合权重。
3. 新候选必须采用嵌套时间协议：内部训练折做表达式和参数选择，外层 purged/CPCV 做
   研究验证，随后 walk-forward 模拟部署；所有搜索继续进入 Trial Ledger。
4. 加入季度衰减门禁：RankIC、路径盈利率或增量收益连续两个季度恶化时自动降级，禁止
   用全年均值掩盖结构性翻转。
5. 统一执行门禁：20 条非重叠路径、匹配暴露对照、1–3 倍成本、300–2,000 万资金、
   邻近广度、置换检验、DSR/PBO 和容量审计。
6. 2025 已被本轮打开，不能再作为新候选的最终测试。下一份真正独立证据应来自冻结后
   的前向 shadow；现有计划从 2026-08-19 开始记录，至少积累 6–12 个月。

短期可以继续在 2022–2025 做探索和嵌套 walk-forward，用于改进研究方法；但只能报告为
开发证据，不能冒充新的独立 Alpha 验证。
