# V4.3 — Information-domain breadth and forward shadow protocol

V4.3 treats search breadth as the number of independent information mechanisms, not the
number of parameter combinations. It unifies every predeclared safe-DSL generation plan,
canonicalizes formulas by fingerprint, and applies a deterministic budget per information
domain.

The active retrospective domains are daily price/volume, opening auction, fund flow, margin,
chip distribution, and limit-event data. Historical industry membership, fundamental PIT, and
news/research text remain explicitly deferred until their point-in-time contracts are adequate.

The frozen temporal protocol is:

- 2022: discovery and domain screening.
- 2023: confirmation and unconditional BUY/AVOID/TIMING mapping.
- 2024: one-shot retrospective diagnostic only.
- 2025 and 2026: sealed against historical search.
- 2026-08-19 onward: append-only paper-shadow evidence, with no live trading.

The `v4.3-domain-breadth` command writes JSON plus Chinese and English Markdown reports. Local
data paths remain in the gitignored `configs/qd-paths.local.json` file.
