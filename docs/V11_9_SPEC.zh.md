# V11.9 连续账户与调仓日历挑战

目标：解释年度重置回测与连续资金表现差异，并判断冻结候选是否依赖单一调仓起点。
承接 Issue184，预注册评论5559351596；不改变两条V11.7公式或方向，不读取2025/2026。

## 固定实验

- 同一冻结快照、2023–2024已暴露开发窗口、一次投入300万元。
- 两条候选及各自覆盖匹配的低波动/hash对照，20日周期、Top40、10档缓冲。
- 四个固定起点0/5/10/15交易日，不代表所有20个可能起点。
- 四个25%目标持仓批次合成一个净额账户；仅在批次更新时重平衡整体目标。
  其他批次的目标保持不变，但实际权重漂移也会随整体重平衡纠正；不是四个独立账户。
- 起始未投入批次保留现金，不用历史事后回填初始持仓。
- 另一个日历每年重置选股状态与起点，但资金、实际持仓一直延续。
- 所有6政策×6日历×2成本=72新试验预记，即使其中连续基线是原样重放也保守计数。
  历史最低试验数3184→3256，失败不退款，单个前驱只允许一次后继占用。
- 标准41与双倍82bps模型；不平均事后NAV，实际重跑相同复权碎股执行器。

## 判断与限制

只以事前确定的四批策略筛选经济性：双倍成本两年均正、连续Sharpe至少0.7、总回撤不超过25%、
比匹配低波动总收益多至少3个百分点、各年增量至少-5个百分点、跑赢hash；四个单相位至少三个
增量为正、最差不低于-5个百分点。完整披露所有日历，禁止挑最优相位作结论。

描述性分解：年度重置链接收益－连续账户年度日历收益＝账户重置差异；后者－全连续起点0收益＝
日历差异。差分顺序固定且总和可核对，但不是唯一因果分解。年度收益必须从同一连续日收益按年聚合。

对12个候选日历的双倍成本活跃收益计算20日purge/5日embargo CPCV、PBO、placebo与原始试验数
DSR敏感性。局部family与已暴露窗口不能提供全历史校准或独立证书。保留全部原有Court门槛。
复权碎股、线性费用、ADV容量不能冒充真实手数、最低佣金、公司行为及开盘成交验证。
只有经济线索幸存才冻结其分批政策并进入执行/风格审计；没有幸存者则保留失败、设计下一有限机制。
