# V2.3：冻结信号的当日风格残差化

## 目标

V2.3 只检验一个预注册假设：移除冻结 V2.1 信号在决策时点的价格动量和流动性暴露，
能否改善 Top-5 的可执行风险调整收益。本轮不搜索新因子、持仓宽度、持有期或阈值。

## 为什么不做行业中性化

现有申万文件是行业指数历史，不是带 `effective_at / available_at` 的历史个股行业成员。
用当前行业分类回填 2022–2024 会产生时间泄漏。因此 V2.3 对行业中性化保持 fail-closed，
改用当前数据可严格支持的两个控制变量：

- 冻结的 `price_momentum_5_20d`；
- 过去 20 日平均成交额的对数。

OLS 只在每个决策日的当日截面内独立拟合。未来收益只作为标签，不参与残差暴露估计。

## 冻结边界

- 数据快照：`99b037baf97721ab438c54392b419ea96c994b68ef616a20b5fa234223928b23`。
- 信号：`flow_confirmation_20_20d`，指纹
  `13f4ddc002cb8f0bb59f057895f3fe8ca89eeb4a819820c11041f043ac8c117e`。
- 价格控制指纹：
  `dfa56be1f549e0ad3414e4319ef8a5f4b00cb02186e7ebca293d13334ef458ec`。
- Top-5、20 日持有期、300 万元和 V2.1 成本/容量模型保持不变。
- 研究数据为 2022-01-04 至 2024-12-31；2025/2026 继续封存。
- 继承 42 次 trial，新增一个候选和一个反向排序负对照，累计 44 次。

原始 Top-5 必须以机器精度复现 V2.1 的收益、Sharpe 和回撤。既有证据由规范化
SHA-256 哈希绑定。

## 预注册门槛

只有全部满足以下条件，才能通过 Alpha Court：

1. 原始对照精确复现，残差信号确实发生变化；
2. 与两个控制变量的平均绝对相关性均不高于 0.01；
3. 年化净 Sharpe 不低于 0.5265716607；
4. 最大回撤不差于 -25%，净收益为正，无容量裁剪；
5. 反向排序年化 Sharpe 不高于零；
6. 两类安慰剂 p 值均不高于 0.05，继承 PBO 不高于 0.20，trial-aware DSR 不低于
   0.95；
7. 封存窗口访问标志均为 false。

如果执行门槛通过但统计门槛失败，只能判为 `PROMOTE_RESEARCH_ONLY`，不能称为 Alpha。

## 运行模式

- `dry-run`：校验配置和本地数据键，不修改 registry。
- `research`：执行冻结对照、两次注册 trial、证伪和双语输出。
- `replay`：无需数据路径，核对三项产物哈希和累计 trial 数。
- `kill`：在访问数据或 registry 前停止。
