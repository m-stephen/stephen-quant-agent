# V11.21 B3：历史特征至账户的合成集成

## 结论

已连接冻结两源读取、逐历史日响应模型、训练矩阵、监督预测及连续账户。这里证明的是工程链路可运行且部分关键计算可独立核对，**不是发现了 Alpha**。未对真实 V11.21 数据启动实验；历史试验债务仍为3660，新实证 Trial 为0，真实回测和 Alpha Court 为 NOT_RUN。

## 新增连接

- `qmt/flow_response_panel.py`：按显式全局日历生成过去20个日收益的样本波动率、20日收益及最多60日平均成交额；日K金额从千元转元。风险历史要求至少21个连续日价格，不压缩缺失交易日；ADV至少1000万元，名称非空且非ST。所有合法可见价格仍保留为持仓估值bar，不因未入选而删掉。
- 缺少紧邻上一全局日的可见ADV，开盘容量为0；当前/未来成交额不能补这个容量。日K在自身EOD不可见时先排除，不能事后回填。沿用源复权价、开盘涨跌停推断、5%过去ADV容量、停牌和20日核销模型。
- `flow_response_history.py`：在读取源文件前，检查预先登记的日历、源manifest、实验快照、provider与consumer关系及未拟合状态，独占领取输出目录。源树与输出树必须分离。
- 逐日响应bundle由当日之前60日数据拟合、写入独占文件并绑定原生记录。完整原生拟合完成后，逐个执行时点核验文件，再计算当日响应特征与风险交集；不存在年度模型倒填历史的路径。
- 实际 `history.json` 字节SHA写入provider的不可变结果，连同源证据及原生模型集合摘要。监督入口不接受任意特征矩阵，只从这份绑定文件构建成熟前缀标签，并将历史文件/训练前缀证据写入模型。读缓存时同时核验各bundle的实际字节与原生记录。
- `flow_response_accounts.py`：七种预测形式及同支持hash/lowvol对照连接四相位净额账户。每格2只、top3留存缓冲、每只2.5%，0/5/10/15四批启动；空支持保留现金，不在剩余股票间重新归一化。300万元，82/164bps，target_changes。原始lowvol/stable锚点尚未接入，不能拿新同支持对照冒充旧锚点。

## 独立核验与边界测试

合成夹具为80只股票、300个工作日（不代表交易所节假日日历），仅有日K和资金流两个实际Parquet。完整关系包含1个provider和9个consumer；这是临时测试库中的10个合成Trial，不是新增实证试验。

1. 用独立NumPy运算从原始合成日K/资金流复算第61、140、255个历史时点的60日标准化、响应斜率、残差、风险和最终分格排名。统计计算不调用生产桥接/响应拟合/响应特征函数；排名函数仍共用，不能称为所有算法完全独立实现。
2. 七个监督形式使用相同成熟训练行摘要，均绑定实际历史文件；训练至少30个实际成熟日期，标签截止严格早于2023。
3. 九个政策均进入标准与双倍成本账户。首个2023信号日故意设为ST、产生空支持：该相位保留现金；另三批启动后75%目标暴露，第一批下次刷新后才补至100%。逐笔成本按买18、卖23bps乘2/4复算，逐日NAV=现金+持仓市值及收益率恒等式核对。
4. 覆盖矩阵/bundle/预测模型文件篡改、缺失来源关系、错年份/政策、错源manifest/日历/快照、重放、输出重叠/已存在、全局缺口、不可见数值毒化、复权连续性、无成交、当前ST/低流动性及未来追加不改变历史等场景。

初始合成集成暴露Parquet常量的Decimal与float混算问题，reader现明确将数值列投影为DOUBLE，保留实际原文件哈希；无效转换失败，不猜测时区。测试夹具名称`Test`会按原ST规则被排除，已改为不含ST的普通合成名。账户检查使用实际`end_nav`字段。初始失败JUnit保留，不能加总为通过数；最终结果见 VERIFICATION。
