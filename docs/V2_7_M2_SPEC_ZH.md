# V2.7 M2 — 折内价格风险控制

## 授权边界

M1 只允许市场 Beta、实现波动率、ADV 流动性、短期反转和中期动量。PIT 股票行业归属及修订安全的市值仍不可用。

## 设计

- 决策时点的每个特征只能使用严格早于该时点的历史。
- 中位数、稳健尺度、缩尾边界和残差化系数只在训练折拟合。
- 留出样本复用不可变且带 SHA-256 的拟合状态。
- 字段变化、非有限值、重复观测、把训练行送入留出变换及状态篡改均 fail closed。
- 部分风险模型永远没有 Alpha Court 资格。

工程审计不使用真实候选收益、IC、回测、placebo、原始目录、远程模型或 2025/2026 数据。
