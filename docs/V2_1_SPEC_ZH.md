# V2.1：真实 QD Alpha 发现与可靠性校准

## 目标

V2.1 将 V2.0 的可审计研究循环接入真实 QD 数据，形成一条可重复执行的
`数据门禁 → 机制假设 → 训练筛选 → CPCV → 成本回测 → Alpha Court → 离线重放`
链路。候选通过统计验证前只能称为研究信号，不能称为 Alpha。

## 冻结边界

- 研究数据：2021-07-01 起提供预热，仅在 2022-01-04 至 2024-12-31 评价。
- 封存验证：2025-01-03 至 2025-12-31，本版本禁止读取。
- 最终测试：2026-01-05 至 2026-12-31，本版本禁止读取。
- 资金：参考净值 300 万元；显式计入佣金、印花税、滑点和冲击成本。
- 搜索：13 个经济机制族，每族只变更 5/20 日窗口，共 26 个预注册候选。
- 推断：所有筛选、CPCV 和执行尝试均进入 trial ledger；最终采用 DSR 与 PBO 修正多重尝试。

## 数据门禁

真实研究启动前必须同时满足：日线与逐日基本面精确匹配、研究期交易日覆盖、
动态股票池规模、资金流/集合竞价/融资融券/行业数据覆盖、冻结快照哈希和本地路径脱敏。
任一检查失败即停止，且不写入研究试验。

## 运行模式

- `dry-run`：只校验配置和所需数据源，不读研究数据、不写 registry。
- `readiness`：生成中英文数据门禁报告和动态股票池。
- `research`：执行完整研究链路并生成重放清单。
- `replay`：离线核对关键产物哈希，不依赖本地数据路径。
- `kill`：在数据或 registry 访问前停止。

本机路径只写入 `configs/qd-paths.local.json`；该文件、原始数据、`reports/` 和
`artifacts/` 均被 Git 忽略。

## 验收目标

1. 小型固定样本与全量单元测试通过，静态检查通过。
2. 真实数据门禁为 `READY`，报告中不存在本机路径。
3. 生成不少于 12 个机制不同的候选族，候选及推断试验完整计数。
4. CPCV、安慰剂、DSR/PBO、成本和容量门禁按冻结阈值运行。
5. 2025/2026 访问标志均为 false。
6. 离线重放和 registry 审计通过。
