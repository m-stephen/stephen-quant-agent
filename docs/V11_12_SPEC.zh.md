# V11.12 冻结配置执行证据契约

Issue #184；运行前登记评论 5560402441。基于 PR #189，在独立堆叠分支实现。

## 目的

查明 V11.11 稳定低风险观察的执行证据缺口，不寻找更漂亮的历史参数。
不改变候选卡、持仓政策、目标或旧结果；不是原股数回测，不授予 Alpha 资格。

## 固定范围

- 2023–2024、300万元、82bps，两组已经冻结的账户：stable_lowrisk、lowvol。
- 原价来自同一冻结 daily.parquet；快照、账户、原始候选卡先验证 SHA-256。
- 单笔买单向下取整：沪深主板/创业板100股倍数；科创板最小200股、1股递增。
  只覆盖声明的历史代码规则；未知市场、无原价不得偷偷归为可执行。
- 6bps佣金、最低5元仅为固定假设；原单净买卖金额不变时计算额外费用。
- 上日持仓的复权因子变化与原价缺失生成私有复核键。不反推分红、送转或配股。
- 声明无拟合的两个原生 diagnostic Trial：3320→3322；新账户0、新拟合0。
  claim独占、失败保留、禁止重复操作。不得重跑已完成的旧研究来美化结果。

## 不可作出的结论

累计舍入金额不是损失、收益差或每日闲置现金。最低佣金加总不是修正净值。
小数份额不是原股数。复权因子不是公司行为现金流账本；不变也不能证明没有事件。
零股卖出、T+1库存、到账时间、分红税和真实开盘流动性仍待验证。
2025/2026不得读取；历史研究窗口不会变成新的独立样本；Court标准不降低。

## 验收与复现

17项新增测试，全套回归；独立SQL费用核对、买入最大可行数量/预算约束、
冻结账户哈希、完整持仓复核集合和SQLite结果对齐。中英文报告、JSON和Notebook。
