# V11.7–V11.8 增量因子实验

开发依据：[Issue182](https://github.com/m-stephen/stephen-quant-agent/issues/182)。

目标是找到值得前向复核的历史线索，不是批准实盘或宣布通过 Alpha Court。

## 已冻结方案

1. 复用 V11.6 五源冻结快照，只使用2023/2024开发收益；不读取2025/2026。
2. 第一批16个公式：70%低波动排名 +30%机制排名，8个字段、正反方向，20交易日调仓。
3. 若没有线索，自动执行第二批16个公式：在波动率最低30%股票内按机制排名，60交易日调仓。
4. 每个字段/期限配套无信号哈希Top40及低波动Top40对照；覆盖集合相同。所有组合40持仓、10档缓冲，每年独立300万元。
5. 无成本/标准41bps/双倍82bps分别运行。32个候选及32个控制策略，共192个成本变体在读取价格前全部预留/登记。未执行预留也保守保留在全局次数内。
6. 本轮原始次数下界2866+192=3058。中断不得清零；后续operation必须携带前次目录。

## 历史线索停止条件

双倍成本下两年均盈利、拼接日收益Sharpe>=0.7、年度回撤不低于-25%；复合年度财富相对匹配低波动控制组多至少3个百分点，任一年不能落后超过5个百分点；相对哈希控制组复合财富为正增量。会计、时序、快照必须通过。

两年账户独立重置，复合只是归一化年度链接，不是连续交易账户。两年都已暴露；按其结果择优属于历史后选择，不是样本外验证。

## 不变的限制

复权价格、分数股、固定成本、前期ADV容量仍是工程近似。哈希对照是相同持仓规模的内部对照，不是指数，不代表完整可投资性。缓冲以此前目标持仓而非实际成交持仓计算；停牌/缺数连续20会话减记规则不变。

字段沿用现有available_at时间；不因结果差而把分钟或竞价数据提前。DSR/PBO/placebo保留诊断和不可识别说明；60日持有使用60日purge上界。旧Court阈值不变。

## 复现

复制`configs/incremental-alpha.example.json`为gitignored的`*.local.json`，设置冻结输入、前置账本和输出路径。

`python -m stephen_quant.workflows.v117_incremental_epoch --config configs/incremental-alpha.local.json`

候选独立重放：`python -m stephen_quant.workflows.v117_incremental_epoch --replay <operation>`。必须使用同一运行时代码；重放不增加Trial。

工程顺序：单测及失败路径检查→真实有界批次→冻结线索→独立重放/逐日对账→双语结果及PR。没有线索则记录失败后提出新机制，不放宽判定。
