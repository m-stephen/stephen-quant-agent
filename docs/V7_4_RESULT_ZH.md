# V7.4 新机制自动因子发现测试报告

## 结论

V7.4 完成了两批有界、可审计的自动因子搜索，但**没有发现可部署 Alpha**。最终结论为 `REJECT_ALPHA_COURT`。2025/2026 封存窗口均未打开，所有失败尝试均计入累计 Trial。

这轮并非没有发现统计信号：多个候选具有显著 RankIC、placebo p 值 0.005，第二批甚至出现 35/35 条 CPCV 正路径。但这些信号没有稳定转化为扣除成本后的组合收益，且 PBO、DSR、Sharpe 与回撤门槛仍失败。

## 冻结协议

- 研究数据：2022-01-01 至 2024-12-31。
- 2025/2026：保持 sealed，未读取、未调参。
- 资金：人民币 300 万元。
- Epoch 1：5 日预测、Top 10、48 个方向候选、24 个 CPCV 名额、12 个执行名额。
- Epoch 2：20 日预测、Top 20、32 个方向候选、16 个 CPCV 名额、8 个执行名额。
- 标准成本：佣金 3 bps、卖出税 5 bps、滑点 5 bps、冲击系数 10 bps、最大参与率 5%。
- 双倍成本压力测试保持启用。
- 门槛：DSR >= 0.95、PBO <= 0.05、placebo p <= 0.05、年化 Sharpe >= 0.50、最大回撤 <= 25%。

## Epoch 1：新机制语法

生成 24 个机制公式并测试正反方向，共 48 个候选。覆盖价格风险、路径质量、Amihud 流动性、资金流冲击、融资需求、筹码结构及跨源交互。

| 指标 | 结果 |
|---|---:|
| Screening Trials | 48 |
| CPCV 候选 | 17 |
| 完整 Court 候选 | 12 |
| Court 累计 Trial | 234 |
| PBO | 0.1000（失败） |
| 最佳 DSR | 0.1383（失败） |
| Placebo p 值 | 0.005 / 0.005（通过） |
| Walk-forward 收益 | 28.77% |
| Walk-forward Sharpe | 0.5733 |
| Walk-forward 最大回撤 | -28.72%（失败） |

表现最好的执行候选是“融资净买入压力反向”：

- 标准成本收益 21.68%，年化 Sharpe 0.3500，最大回撤 -35.71%。
- 双倍成本收益 4.33%，年化 Sharpe 0.1915。
- 容量门禁通过，但 Sharpe、回撤、PBO 和 DSR 失败。

## Epoch 2：跨源确认与慢周期

生成 16 个跨源确认公式并测试正反方向，共 32 个候选。覆盖资金流×融资、资金流×筹码、融资×筹码、价格路径×替代数据。预测周期改为 20 日，持仓扩展到 Top 20。

两次工程预检在记录 32 个 screening Trials 后，因 CPCV 路径配置定位错误而失败关闭。64 次尝试均保留在累计 Trial 中；最终纠正轮从 298 次历史 Trial 起算。实际配置固定为 7 组、3 个测试组、至少 15 条正路径。

|---|---:|
| 最终轮 Screening Trials | 32 |
| CPCV 候选 | 14 |
| 完整 Court 候选 | 8 |
| Court 累计 Trial | 360 |
| PBO | 0.0571（失败） |
| 最佳 DSR | 0.1804（失败） |
| Placebo p 值 | 0.005 / 0.005（通过） |
| Walk-forward 收益 | -7.81% |
| Walk-forward Sharpe | 0.0151 |

Epoch 2 最佳标准成本候选仍亏损 8.38%，年化 Sharpe 0.0039，最大回撤 -34.18%；双倍成本亏损 13.02%。因此慢周期与 Top 20 分散并未解决可交易性问题。

## 可靠结论

1. 扩展机制空间有效提高了统计信号覆盖，证明系统已经能自动生成并筛出“看起来很强”的候选。
2. RankIC、placebo 与正路径数不足以代表可交易 Alpha。第二批多名候选达到 35/35 正路径，但组合收益仍为负。
3. 当前主要矛盾已从“搜索范围太窄”转为“候选表达与投资组合目标错位”。原始量纲信号直接相乘容易放大尾部和极端值。
4. 增加持有期和股票数没有自然降低回撤，说明风险来自信号状态切换和组合映射，而不仅是交易成本。
5. 在同一 2022–2024 窗口继续无界生成类似公式，只会增加 multiplicity；本轮在两个预注册机制批次后停止是必要的完整性约束。

## 工程成果与下一步

- 新增方向完整、来源感知的机制组合语法。
- 新增跨源确认机制与独立 CLI。
- 相同公式的正反方向共享原始观测面板，方向身份和 Trial 仍独立；真实运行内存峰值由约 11.6 GB 降至约 7.6–8.5 GB。
- CPCV 配置抽取为可直接验证的冻结配置，昂贵计算前即可检查路径可行性。
- 发布前审计发现哈希 schema ID 未命中机制族预算标签；两轮实际 shortlist 均天然满足原上限，因此结果不变。代码已改为配置存在时优先使用 `schema.event`，并增加回归测试。

下一阶段不应继续堆原始乘除公式。建议依次实现：

1. fold-local 横截面 rank/z-score 后再组合，消除量纲和极端值主导；
2. 以净收益、回撤、换手和路径稳定性构造 portfolio-aware 训练目标；
3. 在训练 fold 内做行业/规模/波动中性化与状态切换诊断；
4. 持久化共享特征矩阵与 CPCV 路径缓存，提高正交搜索吞吐；
5. 获得真正新增时间数据后，对冻结候选做 append-only 前向验证。

在上述能力或独立新数据到位前，当前候选均不得部署。
