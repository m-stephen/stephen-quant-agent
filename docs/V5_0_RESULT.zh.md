# V5.0 全市场平衡股票池 Alpha 搜索结果

## 结论

V5.0 修复了原先流动性 Top50 股票池过窄、偏向大盘股的问题，并找到目前最值得进行
前向验证的双域候选组合；但冻结结论仍为 `NO_DEVELOPMENT_ALPHA`，不能宣称已经发现
可靠 Alpha。唯一失败项是累计 1,206 次推断性尝试后的 DSR 多重性门禁。

入选组合为：

- `chip_cost_gap_reversal_5_20_20d`：价格相对近5日筹码加权成本越高，未来20日越偏向
  反转；经济含义是获利盘兑现压力。
- `flow_price_divergence_20_20d`：20日净流入强度减去同期价格涨幅；资金持续流入但
  价格尚未充分响应时，未来20日可能存在补涨。

两者日度 IC 相关系数为 0.1337，满足跨域正交要求。36个预声明候选中4个通过跨年
稳定性筛选，最终只提升这两个候选到完整验证面板。

2024是已经重复使用的 shadow 证据；2025/2026没有用于本轮生成或调参。

## Alpha Court

| 门禁 | 冻结要求 | 结果 | 状态 |

| 正压力情景占比 | >=75% | 100% | PASS |

| 收益 placebo p | <=0.05 | 0.005 | PASS |
| DSR | >=0.95 | 0 | **FAIL** |

DSR 使用实际增量日收益的偏度 1.1900、超额峰度 5.9708，并把前序试验、本轮中止但
已揭示的46次试验以及最终46次复跑全部计入，总 Trial 数为1,206。正偏和厚尾没有改变
多重性结论：历史搜索规模已经足够大，当前回测不能提供达到0.95的去膨胀置信度。

## 下一步

1. 冻结该双域组合的公式、等权秩合成、Top50、20日持有期、成本和股票池规则，不再
   使用2022–2026调参。
2. 把它登记为前向候选，在真正新增交易日上做 append-only 验证；至少累计25个共同
   新交易日后运行一次不调参续验。
3. 新 Alpha 搜索应使用不同经济机制和独立 trial budget，优先公司行为、融资融券、
   竞价微结构等正交域；不能围绕本组合继续扫近邻窗口。
4. 在前向数据到来前，优化数据缓存和分块计算，降低完整验证面板约13GB峰值，但不得
   改变样本或统计定义。

## 证据边界

- 数据与成员快照 SHA-256 已冻结；真实原始数据和本机路径未进入 Git。
- 2022–2024均为重复历史开发证据，不是独立样本外证明。
- `NO_DEVELOPMENT_ALPHA` 不等于组合无效；它表示证据强度尚不足以抵消累计搜索偏差。
