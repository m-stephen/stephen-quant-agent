# V3.0 持续因子研究循环

## 目标

在不降低 Alpha Court 门槛、不打开 2025/2026 封存窗口的前提下，按冻结研究纪元持续
探索新的经济机制。失败候选进入墓碑库；后续纪元必须更换机制，不能依据已观察结果继续
调整同一公式。

## 研究纪元

- 研究期：2022-01-04 至 2024-12-31。
- 每个纪元最多 3 个 Schema、3 个 CPCV、3 个成本执行候选。
- 已预注册机制依次覆盖：需求加速度、拥挤/流动性、筹码水平、筹码动态、涨停事件。
- 多重检验：继承 V2.9 结束时的 52 次推断试验，再累计本纪元全部尝试。
- 执行：300 万元参考净值，佣金、印花税、滑点、冲击成本和 5% ADV 上限显式计入。

## 不可修改门槛

- 训练期平均 RankIC 至少 0.005；CPCV 路径平均 RankIC 至少 0.015；
- 至少 8 条 CPCV 正路径，PBO 不高于 0.05；
- 两类 placebo p 值均不高于 0.05；DSR 不低于 0.95；
- Walk-forward 成本后收益必须为正；
- 300 万元组合年化净 Sharpe 至少 0.50，最大回撤不差于 -25%；
- 2025/2026 访问次数必须为零。

单个纪元失败后，只有新的预注册经济机制才能启动下一纪元；当前数据机制预算全部耗尽后
输出 `NO_ALPHA_IN_CURRENT_MECHANISM_SET` 并停止。通过 Alpha Court 也只表示研究证据，
仍需独立验证和容量/风险复核。
