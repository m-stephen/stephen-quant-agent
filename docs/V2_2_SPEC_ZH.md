# V2.2：冻结信号的组合宽度研究 Epoch

## 目标

V2.2 只回答一个有边界的问题：扩大持仓数量，能否改善 V2.1 冻结信号的可执行风险调整
收益？运行前固定信号、数据快照、研究区间、成本模型、资金、持有期与选择规则。本版本是
组合构造实验，不是新一轮因子搜索。

## 冻结边界

- 信号：`flow_confirmation_20_20d`，指纹
  `13f4ddc002cb8f0bb59f057895f3fe8ca89eeb4a819820c11041f043ac8c117e`。
- 数据快照：`99b037baf97721ab438c54392b419ea96c994b68ef616a20b5fa234223928b23`。
- 研究区间：2022-01-04 至 2024-12-31；2025 与 2026 继续封存。
- 参考资金：300 万元；沿用 V2.1 的佣金、税费、滑点、冲击与容量约束。
- 持有期：20 个交易日。
- 唯一变量：`top_k` 为 5、10、15、20。
- 选择规则：原始净 Sharpe 最高；相同时选择更小的 `top_k`。
- 多重性：继承 37 次 trial，新增 4 次宽度实验和 1 次反向排序负对照，累计 42 次。

既有证据字段通过规范化 SHA-256 哈希绑定。Top-5 必须以机器精度复现 V2.1 的年化净
Sharpe、净收益和最大回撤，否则立即失败，禁止继续比较。

## 预注册门槛

只有同时满足以下条件，才接受组合宽度升级：

1. 最终选择不能仍是 Top-5；
2. 年化净 Sharpe 不低于 0.5265716607，即比 V2.1 至少提高 0.10；
3. 最大回撤不差于 -25%；
4. 净收益为正，且无容量裁剪；
5. 反向排序年化 Sharpe 不高于零；
6. 两类安慰剂 p 值均不高于 0.05，继承 PBO 不高于 0.20，DSR 不低于 0.95；
7. 2025 验证窗口和 2026 最终测试窗口均未打开。

任一门槛失败即拒绝，不得临时降低阈值或改用第二套选择规则。

## 运行模式与证据

- `dry-run`：校验冻结配置和本地路径键，不读取研究数据、不修改 registry。
- `research`：登记 5 次 trial，执行四种宽度与反向负对照，重跑安慰剂、计算 DSR，
  输出 JSON 和中英文报告。
- `replay`：无需本地数据路径，离线核对产物哈希与累计 trial 数。
- `kill`：在访问数据或 registry 之前停止。

本机路径、原始数据、registry 和生成报告继续由 Git 忽略。
