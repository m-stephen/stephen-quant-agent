## 资源监督与限制

新增监督器仅操作自己创建并持有句柄的 Windows 子进程：显式 argv、隐藏窗口、不用 shell，剥离 Alpha派凭据环境变量。启动前验证有限正值资源限制和命名 SHA-256 证据；运行中记录内存、可用物理内存和实际 UTC 时间。

成功、预启动拒绝、私有内存/可用内存/时间保护、测量异常、非零退出、中断和终止失败都保留终态记录；不自动重试，不覆盖旧 operation。零退出但没有任何资源采样也不能声明完成。终止失败明确标为 `TERMINATION_FAILED`，不谎称进程已停止。

它是**监督原语，不是实证授权入口**。轮询不是 OS 硬限制；仅覆盖该进程而非任意后代进程树；底层源行/历史/rank 面板仍可能完整驻留。断电或磁盘不可写可能只留下启动/日志/样本。未来入口仍须在数值读取前绑定父结果、原始源/目标、代码、实际预登记与完整 23 次 Trial，并做跨 operation 独占。
