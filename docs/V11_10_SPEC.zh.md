# V11.10 训练期残差机制与换手门槛

## 研究问题

既有筹码四批候选保留冻结观察，不能因历史盈利而称作可用 Alpha。
本轮检验三个事先固定的交互机制是否具有超越简单风险暴露的预测信息。
2022–2024 都是已接触历史；2023/2024 为复用开发，不是新 OOS。不读取2025/2026。

## 方法与完整预算

- 三机制：资金净流入×20日反转、筹码成本分布宽度×20日反转、竞价收益×尾盘反转。全部使用同一日已知横截面居中秩；方向由训练数据的残差斜率决定，不另扫正反方向。
- 共同覆盖同时要求波动率、20日收益、ADV、资金流、筹码、竞价和尾盘字段；不将缺失值填成0，不增加数据源。
- 2023模型仅训练2022；2024模型训练2022–2023。先按训练截止切片，再构造下一开盘至20交易日后开盘收益，完整标签须成熟，另留5交易日embargo。每5交易日采样。
- 训练期OLS剔除截距、波动率秩、动量秩和ADV秩的线性影响；信号和标签分别残差化，残差单变量斜率固定ridge=0.01，不搜索参数。OLS的1e-10对角项仅稳定数值。
- 缺失入场价格排除并计数；缺失到期价格以-100%标签保守处理，不偷偷删掉潜在亏损样本，也不声称该假设证明真实退市损失。
- 5个波动率×4个流动性秩格子，各最多2只、每只2.5%；缺格保留现金。保留仍处于该格的原目标股，空位按固定hash补齐；只当新旧股票预测增量差超过1.22%（82bps+40bps缓冲）才做主动替换。该门槛不禁止必需的覆盖/格子迁移与净额账户重平衡交易。
- 唯一固定0/5/10/15四批合成的连续净额账户，不挑相位，不重置年度资金。低波动Top40/10档缓冲、同格稳定hash为共同覆盖对照。
- 6次年度模型拟合 + 5政策×41/82/102bps三个成本=21次新试验；全部首次读取前预留，历史下界3268→3289。失败/中止和旧未执行预留均不退还。

## 冻结筛选与局限

历史经济线索必须在82及102bps下均满足：两年收益正、Sharpe≥0.7、全程最大回撤≥-25%、相对两个对照的总收益率差均≥3pp、各年对低波动增量≥-5pp、账务复核通过。该规则不等于Alpha Court，不能从三个机制中挑一个就宣布显著。

已有CPCV用于自适应walk-forward收益矩阵的选择敏感性诊断，不是每折重拟合模型的完整嵌套CPCV。DSR仍是当前家族外推全历史Trial下界的敏感性；不冒充全历史校准。2023/2024复用、行业/规模/市场beta未完整控制、7天内分钟特征对齐、供应商时间字段及复权碎股/线性费用/ADV容量局限保持显式。

## 验证及运行

植入残差信号、纯风格空信号、固定随机空信号、未来扰动、标签成熟、缺失出场、共同覆盖、格子限额、成本门槛、预读登记及防重复测试必须通过，然后才允许真实数据epoch。独立核算全部账户并输出中英文JSON/Markdown。不降低DSR0.95、PBO0.05、placebo0.05和既有路径门槛。
