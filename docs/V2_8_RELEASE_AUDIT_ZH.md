# V2.8 数据源升级发布审计

- 包版本：2.8.0
- 分类：`point-in-time-data-source-upgrade`
- 目标分支：`main`
- 工程状态：`DATA_SOURCE_STAGING_READY`
- Alpha 状态：不变；不新增 Alpha 声明
- 新增 inferential trials：0
- 2025：允许维护平面补齐数据，但仍禁止用于新研究
- 2026：允许维护平面按许可的 as-of 时间补齐数据，但研究窗口继续封存
- 实盘：禁用且不授权

## 纳入能力

- 确定性的原始字节 Inventory、相对路径 Manifest、文件大小和 SHA-256。
- 单用户本机路径配置、短期维护 Unlock 和 append-only Ledger。
- 显式 QD 审计 allowlist，原始数据和本机绝对路径不进入 Git。
- 财务双时间与修订链、行业有效区间、公司行为契约和 PIT 市值构造。
- Alpha派分页 Manifest、分页漂移检测、保守可用时间和确定性 PIT Bundle。
- 交易所公告及候选权威数据源的运行时原文绑定。
- 数据源完整性报告，未解决的数据族继续显式失败关闭。

## 已验证的公告补齐

- 2023：6,211 条准入记录、4 个文档身份、quarantine 0。
- 2024：5,858 条准入记录、4 个文档身份、quarantine 0。
- 两次独立 replay 生成完全一致的 bundle SHA-256。
- Git 中不包含原始文档、供应商原始身份、凭据或本机路径。

## 仍保留的发布边界

V2.8 不声明“全部外部数据已经完成”。目前仍缺少带历史生效区间的权威股票级行业成员
数据（#92），公司行为及股本变更的全量权威来源 staging 也尚未完成（#93）。因此
Gate 5（#84）继续阻塞，数据补齐总任务（#75）继续开放。在对应来源门禁通过前，候选
字段不得提升为正式研究元数据。
