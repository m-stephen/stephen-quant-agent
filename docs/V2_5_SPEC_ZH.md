# V2.5：预注册市场状态组合研究周期
保守方式继承，候选、阈值、选择规则和 trial 预算均未改变。
## 目标

V2.5 不修改 V2.3 的因子公式，也不打开 2025/2026。它只回答一个问题：已冻结的资金流
残差信号是否应根据决策时可见的市场状态改变组合使用方式。

市场状态在运行前固定为全体合资格股票五日价格动量方向值的横截面中位数。中位数大于零为
`RISK_ON`，否则为 `RISK_OFF`；阈值固定为零，不训练、不搜索。

## 冻结策略

只允许两个候选：

1. `risk_off_cash`：风险开启时执行残差资金流 Top-5；风险关闭时清仓并持有现金。
2. `risk_off_momentum_fallback`：风险开启时执行残差资金流；风险关闭时切换到价格动量 Top-5。

V2.3 基准仅精确重放，不新增 trial。两个候选各计一次推断 trial，累计账本由 45 增至 47。
观察结果后不得追加阈值或第三种策略。

## 多重检验边界

DSR 使用 47 次累计推断暴露和候选真实收益矩。策略族 PBO 在共同的 35 期收益矩阵上比较
冻结基准和两个候选，但范围必须标记为 `PORTFOLIO_POLICY_SELECTION_ONLY`。它不代表完整
自适应因子搜索已得到校正。

## 验收门槛

工程门槛包括 V2.3 精确重放、PIT 状态输入、共同执行日期、两次新 trial、无容量裁剪、
显式 PBO 范围、离线重放和封存窗口零访问。

Alpha 门槛包括：Sharpe 至少提高 0.10、回撤不差于 -25%、至少三分之二年份为正、最差
年度收益不低于 -10%、年度与滚动 Sharpe 不低于 -0.25、绝对收益前 10% 贡献不高于
50%、安慰剂 p 值不高于 0.05、策略族 PBO 不高于 0.20、DSR 不低于 0.95。

收益集中度门槛是 V2.4 既有护栏；发布审计时发现 Issue 未复述该项后，以只会增加失败的
保守方式继承，候选、阈值、选择规则和 trial 预算均未改变。
