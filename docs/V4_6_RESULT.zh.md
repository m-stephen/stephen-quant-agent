# V4.6 三域正交 Alpha 研究结果

## 结论

V4.6 找到了比单一涨停因子更合理的双域组合，但仍判定 `NO_DEVELOPMENT_ALPHA`。

36个候选中只有两个通过跨年信号门禁：

- `flow_price_divergence_5_20d`：5日资金流强度相对5日价格变化的背离。
- `auction_strength_5_20d`：5日集合竞价收益强度。

两者日度 RankIC 相关系数为 -0.1309，满足正交要求。筹码域没有候选通过跨年门禁。

| 指标 | 组合结果 |
|---|---:|
| 300万元、标准成本超额收益 | +2.80% |
| 完整组合超额夏普 | 0.8250 |
| 相对匹配基准增量收益 | +8.40% |
| 增量日频夏普 | 2.0143 |
| 盈利非重叠路径 | 17/20 |
| 路径夏普中位数 / 下四分位 | 0.4084 / 0.1165 |
| 最大回撤 | -5.08% |
| 信号 / 收益置换 p 值 | 0.005 / 0.005 |
| 2倍成本完整超额收益 | -4.54% |
| 压力测试正收益单元 | 2/4 |
| DSR | 3.76×10⁻¹⁰ |

2,000万元结果与300万元相同且容量裁剪为零，说明问题不是资金容量，而是换手和成本
转换。资金流背离在四年均保持正增量，2025仍为 +1.97%；集合竞价强度在2025转为
-1.40%，拖累组合的时间稳定性。

## 下一步

1. 不扩大候选数量。优先研究降低换手的持仓缓冲、分层替换和最小换仓阈值，并把这些
   规则限制在固定的小网格中。
2. 保留资金流背离作为核心候选；集合竞价信号只能作为确认项，不能单独决定持仓。
3. 筹码域暂时停止扩展，先检查其字段尺度、覆盖率和经济机制是否与价格信息高度重复。
4. 对组合增加逐年和逐季度成本归因，明确毛增量、换手成本和等权基准成本。
5. 建立域级对齐缓存。本轮36候选运行约十分钟、内存约3.2GB，当前重复安全 DSL 扫描
   不适合持续循环研究。
6. 任何后续开发结果仍只能作为2022–2025开发证据；真正独立结论必须进入
   2026-08-19之后的 append-only shadow。
