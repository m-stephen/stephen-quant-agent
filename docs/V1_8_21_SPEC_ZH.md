# V1.8.21 预注册组合使用切片

## 目标

V1.8.20 证明资金背离信号保留残差信息，但主要价值来自回避最低十分位，简单 Top-K 多头未能通过 Alpha Court。V1.8.21 不再搜索新公式，而是在冻结的 2022—2024 研究区间比较有限的信号到组合映射。

## 冻结映射

- 全体可投股票等权基准；
- 最高十分位；
- 最高 30%；
- 排除最低十分位；
- 最低十分位减权至普通股票的 25%；
- 使用预声明控制信号残差化后排除最低十分位。

每个映射在 100、300、500、1000、2000 万元资金规模分别登记 Trial。全体可投股票等权组合用于计算增量收益、增量 Sharpe 与增量回撤；参考组合预先固定为“排除最低十分位、300 万元”，不根据结果选择。

## 完整性边界

- 2022—2024 已是消耗过的研究数据，结果只能标记为 `research_only`；
- 2025/2026 不读取、不列举、不哈希；
- 映射、阈值、成本、容量和资金规模均在测量前冻结；
- 每个映射与资金规模组合都是 Inferential Trial；
- 沿用现有自融资、交易税费、滑点、平方根冲击、成交限制和不可交易处理。

## 验收

相同 manifest 必须产生相同指标；所有 Trial 可追溯；输出中英文报告；无论收益如何均形成版本化 reference portfolio，但不得据此声称获得新的样本外 Alpha。
