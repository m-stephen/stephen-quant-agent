## 已实现的响应表示

对同一只股票，在信号日 t 之前连续 60 个全局交易日拟合。输入为净流量比例 f 和同日源调整口径收盘收益 r；它们在 fit_cutoff 前必须已经可见。使用总体标准差，不使用未来收益标签：

```text
zf = (f - mean_past60(f)) / std_past60(f)
zr = (r - mean_past60(r)) / std_past60(r)
beta = mean_past60(zf * zr) / 1.01
flow_surprise_t = standardized(f_t, past60)
response_residual_t = standardized(r_t, past60) - beta * flow_surprise_t
```

60 日窗口、0.01 ridge 是这个原型的固定设计值，不是从本轮市场回测中挑出的参数。后续收益方向仍须由完整预登记的成熟训练前缀学习，不能按开发集表现翻转正负号。

模型绑定股票身份、预测全局交易日、训练窗口、原始观察哈希、冻结快照哈希和拟合截止时间。必须紧接训练窗口的下一全局交易日使用；缺失或未及时可见的最近数据不得回退到陈旧 60 日窗口。窗口内无效值阻断，滚出窗口后可以恢复。常数输入、非有限数、跨股票应用、错模型哈希、重复或乱序交易日以及时区缺失均拒绝。

合成反例保留相同流量序列、相同当前流量/收益、相同 20 日累计收益，仅改变历史流量与价格响应的配对方式，残差即不同。它证明这个表示不是旧汇总排名乘积的恒等式，不证明预测优势、独立信息或因果冲击。经济家族仍为 liquidity_impact_absorption。
