# V2 M1：从假设到安全表达式

## 目标

把结构化、可证伪的 V2 假设编译为确定性、白名单、PIT-safe 的表达式族。模型只能在冻结蓝图和参数边界内提出选择，不能生成或执行任意 Python、SQL、shell。

## 编译门禁

- hypothesis 的事件和 inputs 必须与蓝图及表达式完全一致；
- 字段和函数必须在 typed DSL 白名单内；
- 加减法执行量纲检查；所有除法必须有显式正数下限；
- lookback、AST 复杂度和字段 coverage 必须满足冻结 policy；
- 字段可用时点不得晚于决策时点；
- 任一检查失败都在数据求值前 fail closed。

## 搜索边界

`EXPLORE` 只从事件对应的唯一白名单蓝图创建候选；`MUTATE` 每次只能修改一个已有 lookback 参数，并保留 parent lineage。队列有硬预算。离线 replay 只解析冻结的原始响应，不提供模型或网络回调。

## 验收

三个资金流/价格、超大单流向、融资需求假设必须确定性编译；非法算子、超长窗口、不安全除法、量纲冲突、coverage 不足和 PIT 越权必须在实证评估前拒绝。
