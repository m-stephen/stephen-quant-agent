# V11.10.1 分阶段拟合血缘与合成成交校准

## 结论

这是工程修复，不是新增行情回测，也没有发现或认证新的 Alpha。
原 V11.10 的真实训练按年份隔离，但旧账本固定写训练期2022，不能准确表达
2024模型训练使用2022–2023。旧实验及附加澄清证据不改写；新试验改用原生阶段契约。
历史真实研究 Trial 下界仍为3289，本轮增量0。2025/2026没有读取或解封。

## 已实现

1. `TrialSpec.fit_stages` 随 Trial 在同一事务中预先注册。
   `None`仅用于兼容旧试验，不代表验证通过；空元组明确表示不拟合的对照。
2. SQLite新增契约及模型证据表，禁止更新/删除。每阶段绑定实际参与训练的
   信号日期列表、训练截止、最大标签到期日、预测区间、模型文件实际字节SHA-256、
   规范化模型内容哈希，以及从所属实验取得的快照和代码标识。
3. 跨年模型分别记录，不再用单个训练区间冒充分年度walk-forward血缘。
   训练区间外记录、未成熟标签、重复/无序日期、模型年份错误、重叠预测阶段、
   不同内容重用同一身份均被拒绝。相同证据重试不增加Trial。
4. `guarded_targets` 在读取特征并计算目标之前检查完整绑定、实际运行模型、
   预测区间，以及训练截止<信号日期<交易日期。缺失阶段不能提交成功结果。
5. `fit_year` 明确输出实际被接受样本对应的训练日期，零有效样本日期不计入。
6. 固定合成数据通过真实状态账户执行，含300万元本金、82bps名义往返成本、
   四批净额目标和禁止买入对照；逐账户现金、持仓与收益账务检查通过。

## 不作过度承诺

合成日期是人工顺序会话，含非真实交易日；固定随机种子和刻意植入强信号仅证明
这条代码路径可以把足够强的预测转为成交，不校准真实市场假阳性率，也不证明弱信号
具有统计功效。成交器仍采用复权碎股、线性费用及代理容量，不是券商级实盘认证。

原V11.10已完成的runner和RESULT保留，不重跑或追认其旧数据库为原生证据。
这次新增的是下一代试验必须使用且已完成端到端测试的入口；旧CLI不会自动获得
原生认证。下一行情epoch须单独预登记，并直接接入新入口，不能拷贝旧债务3268。
原有原生检查只证明被记录数据、运行模型及时间的一致性，不证明供应商数据真实性。

下一步恢复有限机制研究，保留低风险基础对照，优先检验现有数据中的时间持续性/
变化信息；不重复已失败的三个静态交互、不降成本门槛。真实结果仍须接受完整
多重检验、placebo、所需的折内重拟合和独立证据，才可能叫可用Alpha。
