## 有价值的结论与边界

1. 系统并非完全无法发现信号：在明确植入、足够长且可兑现的机制条件下能找回。
   这只证明指定合成分布的完整流程能力，不证明真实市场有同类Alpha。
2. 观察长度有影响：开发360日全强度线性7/8、交互8/8；净重排只有5/8、6/8，
   没有证据替换主政策。每格仅8条，不能宣布净重排普遍无用。
3. 弱效应不会自动被更久历史拯救：半强度线性360/720日，164bps下平均配对
   增量约−0.049/−0.557bp/日，晋级均0/8；成本吃掉信号时，加样本不是经济修复。
4. HAC算式数值核验通过（独立矩阵SE最大差2.78e−17），但固定lag10在强相关
   下置信覆盖不足：120日rho=.8只有82.95%，720日仍87.65%，不能把这些t值当
   普遍校准p值。这不是简单的“验证器太严格”。成本后负均值null也不能证明零均值检验尺寸。
