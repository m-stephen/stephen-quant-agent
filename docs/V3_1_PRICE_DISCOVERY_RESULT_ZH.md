# V3.1 价格因子发现实验结果

## 结论

本轮不是 `COURT_PASS`，但首次得到明确的 `RESEARCH_CANDIDATE`。这推翻了“仅靠 K 线连一个
疑似 Alpha 都找不到”的判断，也验证了旧版的主要缺陷是候选生成器和评价口径过窄。

入选候选为 `ohlc_return_close_120_20d_neg`：过去 120 个交易日收盘收益取反，预测未来
20 个交易日开盘到开盘收益。它是中期反转信号，而不是可以直接实盘的策略。

| 指标 | 结果 |
|---|---:|
| 预声明候选 | 630 |
| 2022 RankIC | 0.227871 |
| 2023 RankIC | 0.111925 |
| 2024 RankIC | 0.108395 |
| 2023 Top-Bottom 平均收益差 | 0.013055 |
| 2024 Top-Bottom 平均收益差 | 0.024131 |
| Purged/embargo CPCV 路径 | 10/10 正向 |
| CPCV PBO | 0.000000 |
| 信号 / 收益 placebo p 值 | 0.005 / 0.005 |
| DSR 概率，按 630 个候选校正 | 0.033388 |
| 20 个 offset 平均扣成本超额 Sharpe | -0.094724 |
| 最差 offset Sharpe | -0.814492 |
| 最差回撤 | -0.335469 |

因此它通过了跨年方向稳定、CPCV、PBO 和 placebo，但没有通过 DSR、经济 Sharpe 与回撤
门禁。严谨表述是：**价格中存在稳定的横截面预测结构，但当前 Top 5 多头实现无法把它转换成
合格的净 Alpha。**

## 本版修正

- 一次性冻结 630 个候选，而不是每轮只试三个硬编码因子。
- 覆盖 2/3/5/10/20/40/60/120/240 日窗口和 1/3/5/10/20 日持有期。
- 每个公式同时预声明正向与反向，负 IC 不再被错误丢弃。
- 2022 只排序并冻结 Top 60；2023 确认，2024 作回顾性影子验证。
- 因子有效性首先看 RankIC、Top-Bottom 和 Top-vs-Universe；多头 Top 5 只是可行性层。
- CPCV 对标签区间执行 purge 和 5 天 embargo；单一幸存者仍可评估，PBO 标为 N/A。
- 经济回测覆盖持有期的全部 offset，而不是只抽取一个起点。
- 候选级多重检验数固定为 630，和审计 Trial 数分别披露。
