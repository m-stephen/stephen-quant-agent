# V4.8 冻结候选：2025–2026 账户收益与市场基准报告

## 技术摘要

按现有20日错位 cohort 会计口径，300万元在2025-01-02至2026-08-14的标准成本净收益为
**36.84%**，净利润 **1,105,111.91元**，期末模型净值 **4,105,111.91元**。相对同股票池、
同路径和同成本的匹配对照，因子增加 **3.12%**，约 **93,530.77元**。

该数字是冻结候选的模型回测账户收益，不是券商实盘对账单。2025属于已参与选择的开发证据；
2026属于一次性封存证据；拼接结果只能用于账户解释，不能被重新标记为完整样本外收益。

共同指数区间内，候选跑赢沪深300和中证500分别为 **22.32%** 和 **7.68%**，但这些差额包含
冻结前50股票池的风格与选股暴露。更保守的同股票池因子增量是 **3.12%**，不应把全部指数跑赢
都称为 Alpha。

## 指标定义与方法

- 绝对净收益：每个错位 cohort 的资金贡献收益扣除佣金、印花税、滑点和冲击成本后，按现有系统口径复合。
- 横截面基准：同一候选股票池全部合格股票的等权20日收益，不是沪深300。
- 匹配对照：同一股票池、20日错位路径、资金和成本下持有全部合格股票，用于隔离因子筛选增量。
- 指数跑赢：在指数文件实际覆盖的共同区间内，因子净收益率减指数价格收益率。
- 股票池：读取动态 membership 的前50只；2024-12-31之后沿用最后一次已知名单。

## 限制与稳健性

- 2025是重复使用的开发证据；只有2026是一次性封存证据，组合账户曲线并非完整样本外结果。
- membership artifact 截止2024-12-31，随后向前沿用至2025–2026；这是冻结股票池测试，不是实时更新股票池。
- 绝对收益沿用重叠 cohort 资金贡献口径，尚未经过独立的每日券商净值对账。
- 沪深300和中证500文件截止2026-07-30，因此指数跑赢幅度只报告到该日。
- 指数比较使用价格指数，因此不包含现金分红。
- 标准成本下平均93.73%的持仓来自缓冲保留；结果大量反映首次筛选和低换手滞回，而不是每日信号持续更新。
- 本报告从2025连续运行并把缓冲持仓带入2026；V4.8封存审计在2026年重新初始化，因此此前的+5.36%完整超额和本报告的2026分段不是同一账户路径。
- 相对指数的跑赢包含冻结前50股票池的市场风格暴露；只有同股票池匹配对照增量更接近因子本身贡献。
- 候选仍未通过冻结 Alpha Court：DSR 0.933929低于0.95。
