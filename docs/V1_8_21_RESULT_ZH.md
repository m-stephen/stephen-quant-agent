## 结论

- **工程验收：通过。** 六种冻结组合定义、五档资金规模、成本/容量模拟、增量基准、Trial 登记、双语报告和封存审计已贯通。
- **回避端价值：相对成立。** 300 万元下，排除最低十分位相对全体可投股票等权基准提高净收益 11.28 个百分点、提高 Sharpe 0.151、减轻最大回撤 5.13 个百分点。

- **Top-decile 仍是绝对表现最好方案，但未通过实盘门槛。** 净收益 +3.29%、Sharpe 0.178、最大回撤 -38.11%。
- **风险控制残差化没有改善结果。** 风险控制后排除最低十分位的净收益为 -15.00%，弱于未经残差化的排除方案。
- **研究决策：保留为 reference portfolio，不晋级 Alpha。** 该结果可作为 V2 Marginal Alpha Engine 的真实相对比较基线，但不能称为新样本外证据。

## 解释

V1.8.20 的残差 RankIC 0.0852 和多空差 4.16% 并没有自然转化为高质量 long-only 组合。V1.8.21 进一步确认：该因子确实能相对改善一个宽基准，但改善不足以把弱市场期的绝对组合转为可接受的风险收益。
