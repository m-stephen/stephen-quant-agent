# V1.8.17 标准化多源因子与因子族搜索规范

关联 Issue：[#27](https://github.com/m-stephen/stephen-quant-agent/issues/27)

## 目标

V1.8.17 不降低 V1.8.16 的验证门槛，而是提高候选信息质量：把价格、成交额、资金流、融资融券和集合竞价组合成可比较的强度、异常与背离因子，并避免同一因子族用多个窗口重复占满搜索预算。

## 冻结设计

- 数据只使用 2024-12-31 及以前的研究区间；2025 验证期和 2026 最终测试期保持封存。
- 每个多源字段必须在交易决策时刻前可得；竞价数据可使用当日 09:26 已发布值，收盘、资金流和两融数据只使用前一交易日可得值。
- 候选按当日横截面截尾、市场中心化和标准化；CPCV 中需要跨样本拟合的变换只能在训练折拟合。
- 候选包括价格基线、资金流/成交额、大单与特大单不平衡、资金—价格背离、两融/成交额、两融余额变化、竞价量价交互、竞价额/成交额。
- 每个因子族最多一个候选进入 CPCV；相关性阈值继续约束近似重复候选。
- 训练筛选目标为 RankIC、正收益年份比例和秩换手代理的冻结组合，不以单一 RankIC 决定入围。
- 正式 DSR 仍使用全局原始 Trial 数，不能用“有效独立 Trial”替代。

## 验收目标

1. 多源 DSL 因子能在严格 point-in-time 规则下生成完整观察面板。
2. 未来可得或陈旧数据会使该观察不可交易，而不是回填或偷看未来。
3. 截尾/标准化参数在 CPCV 场景中只能从训练 ID 拟合。
4. 报告展示因子族、跨年度稳定性、秩换手和多目标分数。
5. 一个命令完成 next-open、5 日、20 日三个期限，输出中英文报告、冻结配置、快照和 Trial 血缘。
6. Ruff、全部测试和 GitHub Actions 通过。

## 非目标和限制

- 不引入 PPO/GNN，不接实盘，不打开封存窗口。
- 行业中性化接口已支持传入 point-in-time 股票—行业映射；现有行业指数文件本身不能证明个股在历史时点的行业归属，因此本轮真实运行只做市场中心化，不伪造行业映射。
- Alpha 派新闻和研报用于未来的假设生成与解释，不能直接替代具有时间戳和覆盖审计的数值因子。

## 一键运行

本机路径只写入已被 Git 忽略的 `configs/qd-paths.local.json`：

```powershell
stephen-quant qd-auto-discover-suite `
  --paths-config configs/qd-paths.local.json `
  --suite-manifest configs/v1.8.17-suite.json `
  --ingested-at 2026-08-17T00:00:00+08:00 `
  --output reports/qd-v1.8.17-suite
```

结果是否为 Alpha 由原有 CPCV、成本回测、placebo、PBO、DSR 和 walk-forward 门槛决定；“可信拒绝”也属于工程验收通过。
