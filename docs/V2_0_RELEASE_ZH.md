# Stephen Quant Agent V2.0（Shadow Mode）

## 可用能力

V2.0 已把“提出假设—安全编译—廉价排重—快速诊断—边际组合价值—结构化失败—下一 epoch 修订或停止”连成可审计闭环。系统可以自动完成受预算约束的工程研究运行，但不会自动实盘，也不保证产生盈利 Alpha。

## 里程碑

- M0：V1→V2 无损契约、分层 ID、Search/Inferential 双账本、Replay Manifest；
- M1：白名单 typed DSL、PIT/static audit、Explore 与单维 Mutate；
- M2：bounded novelty gate、typed cheap diagnostics、冻结门禁 benchmark；
- M3：fold-local residualization 和相对 reference portfolio 的边际价值；
- M4：append-only failure graph、冻结 epoch policy/budgets、STOP_FAMILY；
- M5：单命令 shadow loop、dry-run、kill switch、离线 replay 和双语报告。

## 使用边界

V1.8.21 仍是 research-only reference。`PROMOTE_FOR_FUTURE_VALIDATION` 只表示候选值得在未来独立样本上验证，不表示 Alpha Court 通过。真实 QD/QMT 数据接入、正式 CPCV、placebo、DSR/PBO 和交易成本门禁仍必须在新的预注册实验中执行。
