# V12.0 测试报告：机制能恢复，净增量检出能力仍不足

## 结论

Issue #200 收敛后的 **M0–M2 有界版本已实现并完成一次性合成验收**。
合成功效结论为 **FAIL**：线性／交互植入机制均能被搜索恢复，但扣费且满足统计条件
的晋级率仅为 40%／54%，未达到预声明的 80% 目标。两类 null 的路径误报上界通过。

这不是市场 Alpha 回测，不代表新数据或实盘收益。`validated_alpha=false`，
真实标签新增试验 0，历史 raw attempt 下界仍为 3,733。自动搜索继续暂停；
本轮工程交付不等于批准 M4，也不表示整个 #200 的后续研究已经完成。

## 主要验收结果

保留套件仅开启一次，共完成 **600 条完整路径**，530.36 秒（约 8 分 50 秒）。
每条路径独立生成来源，包含训练选择、子代生成、原生连续账户、经济晋级和评估；
不是把同一市场实例中的候选数当成独立样本。没有异常路径、补种子或人工递补。

| 场景 | 判据 | 事件数／完整路径 | 校正区间 | 冻结门槛 | 结果 |
|---|---|---:|---:|---|---|
| 线性植入 | 恢复且经济晋级 | 40 / 100 | 26.39%–54.79% | 下界 ≥80% | FAIL |
| 交互植入 | 恢复且经济晋级 | 54 / 100 | 39.33%–68.19% | 下界 ≥80% | FAIL |
| 相关结构 null | 任一经济晋级 | 0 / 200 | 0%–3.04% | 上界 ≤5% | PASS |
| 状态波动 null | 任一经济晋级 | 0 / 200 | 0%–3.04% | 上界 ≤5% | PASS |

区间是固定的四场景 × 三检查点（100/200/500）× 双尾 Bonferroni 精确二项边界，
总覆盖错误预算为 0.05。100 次零误报时，上界仍为 5.99%，因此必须继续到 200，
没有用点估计 0% 提前宣布通过。植入场景在 100 次时上界已低于 80%，按约定停止。
这只约束声明的全零分布下路径误报，不能外推为混合真假信号的 FDR 或市场误报率。

## 最有价值的诊断：不是完全找不到公式

| 诊断项 | 线性（100 条） | 交互（100 条） |
|---|---:|---:|
| 精确表达式与方向恢复 | 95 | 100 |
| 预声明经济等价表达恢复 | 100 | 100 |
| 前三名包含真实表达式 | 100 | 100 |
| 最终经济晋级 | 40 | 54 |
| 已知正确表达式在两档成本下均有正日均增量 | 96 | 98 |
| 已知正确表达式通过相同经济门槛 | 41 | 54 |
| 对照通过但搜索结果未晋级 | 1 | 0 |

**这两类已知合成分布中，主要落差发生在表达式恢复之后。** 即使直接提供正确
表达式，并采用同样选定期限、支持集和执行约束，对照也只有 41%／54% 通过。
因此不能把此次 FAIL 简单解释为“生成器无法找出机制”，更不能拿它证明必须买数据。
另一方面，这个对照并非最优组合／最优期限 oracle，不能断言组合设计已经没有问题。

在双倍成本下，线性／交互各有 60／46 条路径未达到 HAC t≥2.5；同一条件下，
日均增量不足 1 bp 的分别只有 6／3 条。失败原因可重叠，不能相加当成互斥归因。
当前 120 日评估长度、噪声和成本下，正净增量并不总能得到足够强的统计证据。
这表明这组“效应强度＋观测长度＋账户＋判据”未达到目标功效，而不是所有 Alpha
验证门槛都应降低。原标准没有因看到结果而改动。

## 下一步建议与边界

1. **保留这次失败，不扩大真实搜索。** 本轮证明有限机制恢复可运行，却没有取得
   目标经济功效；不能用“有合成盈利”给真实 Alpha 背书。
2. 下一份有限规格应先做 **效应强度—观测长度—成本的功效设计**，保持误报与证据
   标准，区分经济可交易与统计可检出。开发题库可以用于设计；新保留验收必须另行
   批准、编号并继承本次失败，不能反复改题直到通过。
3. 在开发侧检查毛评分与有成本连续账户的排序错配，及持有期限／缓冲对收益兑现的
   影响。只做预声明的有限比较，不根据已揭示市场窗口无限改参数。
4. 通过必要能力门槛后，再单独批准一个现有数据上的有限 M4 epoch；不要求先补齐
   所有数据域。历史同频矩阵未提供时正式 Court 仍为 NOT_IDENTIFIABLE/null。
