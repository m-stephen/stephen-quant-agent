# V12.0：有界研究重构实施规格

## 范围与不做事项

依据 Issue #200 原文及评论 5574190768、5574559507、5574601170，首版只实施
M0–M2：合同明确、配对增量测量、合成完整搜索路径校准。基线为 main `50cbc19`，
包版本统一为 `12.0.0`。[English specification](V12_0_SPEC.md)。

本轮不读取真实 QD 数据，不购买或导入新数据，不启动 M4 真实标签研究，不重放旧
operation，不改变 V11.2 的候选、时钟和成本，不恢复自动搜索或执行交易。
历史 raw attempt 下界 3,733 保留。合成 Trial 单独标识，不能清零旧债务，也不与
独立统计试验次数混为一谈。M3 新域按域可选，不成为所有研究的前置阻断。

## M0：复用与缺口

- 复用原生连续账户 StatefulBar / TargetAllocation / stateful 执行器。
- 复用 SearchField / SearchCandidate、快照 SHA-256、原生 ExperimentRegistry。
- 新增严格配对口径、有限 typed DSL、全路径校准与结果分层。
- 既有 V11.21 B5b 的单个强植入恢复证据保留；本轮测试新启用的有限搜索，
  不替代其历史结果，也不证明全部过去／未来算子的功效。
- 暂不实现通用任意 AST、真实域 adapter、神经网络、券商级整手／最低佣金或 M4。

## M1：账户与测量合同

四类账户为 risk-only、risk+signal、signal-only、shuffle。每类运行零费、
82 bps、164 bps 三种往返成本情景，起始资金均为 300 万元。

主比较是 risk+signal 对 risk-only：相同日期、事前可用支持集、风险分组、资金、
维护规则和执行模型；不能要求实际持仓、现金、换手和费用相同。六个合成风险组
各选一只、单只目标 1/6、排名仍在组内前二时保留。signal-only 为全局选股消融，
不宣称相同风险暴露。shuffle 是组内固定错位负对照，不产生市场 placebo p 值。

主序列为 `d_t = r_net(signal,t) - r_net(baseline,t)`。分别输出：

- 配对日均增量、HAC(10) 标准误与描述性区间；
- 两账户累计收益百分点差、相对财富收益；
- `300万 × (信号归一化净值 - 基准归一化净值)` 的人民币增量；
- 主动日差连乘回撤、相对财富回撤；前者不是可直接投资的多空账户；
- 两个预定评估半段、实际费用／成交额及实际风险组权重差。

源和账户使用虚构股票及容量代理，不构成真实市场风险中性、券商撮合或全部订单
独立重建认证。另做标量现金、持仓市值、费用、净值和日收益链核对。

## M2：搜索与合成来源

24 只虚构股票、220 个合成工作日、四个无量纲字段。字段按当日可见性纳入横截面
rank；下一开盘交易，收益注入只使用前一日字段。训练标签在第 95 日内成熟，
第 100–219 日评估（从 0 编号）。不使用评估收益选择父代、方向或期限。

初始 40 个结构：单字段 rank、两字段交互，正负方向，5/10 日维护期限。
训练期选出两个不同字段来源的父代，产生最多八个 gate 子代，总上限 48。
廉价训练评分为组内匹配的毛 horizon spread；最终验证使用有成本的连续基准账户。
这两者并不完全相同，其错配是明确的待测限制，不假装代理评分已经最优。

每条路径预留 48 次训练标签结构评估、12 次原生四账户运行；planted 另有两次
已知表达式对照。因此 planted / null 分别为 62 / 60 条原生阶段 Trial。
同一完整策略在训练及账户阶段重复出现会保留阶段记录；全局策略身份、
策略×来源评估、物理运行和独立推断次数分别报告。每次读取前先预留 Trial。

四个独立来源分布：线性、交互、相关结构 null、状态波动 null。各次重复重新
生成来源及冲击，不只是重复同一数据改变搜索随机数。字段 AR=0.92；线性与交互
强度分别冻结为 0.004、0.012。噪声包括市场、六风险组及个股独立冲击。
不读取或置换真实收益来构造 null。Oracle 不传入搜索器；搜索及账户决策完成后
才用于表达式／语义恢复评价及同约束的已知表达式账户。

已知表达式对照沿用搜索选中的期限，不是全知最优交易。对照失败也不剔除路径。
植入强度是预声明的基准条件，不是假装已认证的最小可检测经济效应。

## 校准、预算与停止

每个场景在 100 / 200 / 500 条完整独立路径处检查。使用精确二项区间，
总校准覆盖错误预算 `delta_cal=0.05` 分配到四场景 × 三检查点 × 双尾。
它不同于路径 FWER 的 0.05 门槛。

Planted 要求“语义恢复且经济晋级”的功效下界 ≥0.80；null 要求整条路径任何
晋级的 FWER 上界 ≤0.05。不宣称混合真假信号下 FDR 受控。
经济晋级要求在 82/164 bps 下均满足：配对日均增量 ≥1 bp、HAC t≥2.5、
两半段均为正。它不是完整 Alpha Court，不替代历史 DSR/PBO/placebo。

开发套件可带记录复测；保留套件 `v12.0-reserved-audit-1` 只开启一次，冻结代码、
运行时、生成分布、种子计划、预算及门槛。最大每场景 500 条、总 2,000 条／四小时。
已确认失败可提前停止；边界未定输出 INCONCLUSIVE；异常输出 ENGINEERING_FAIL，
保留部分账本并消费该 operation，不把缺失或崩溃案例算作正确 null 拒绝。
不换种子、不追加次数、不自动递补或开启下一版本，保留全部开发与失败记录。

## 交付与解释

提供 `stephen-quant research-reset status / plan / run`，命令详见英文规格。
`status` 只预览静态合同，不加载历史验收结果；已执行套件以绑定 hash 的
RESULT / TERMINAL 及报告为准。未安装的新工作区应设置该工作区的 `src` 为
PYTHONPATH 后用 `python -m stephen_quant.cli research-reset ...`，避免误用其他
工作区的旧 editable 安装；NumPy 来自 `[research]` 或 `[dev]` 依赖。
CLI 没有真实源路径选项；输出必须为新的 artifacts 子目录，共享计划及消费记录
在本机 gitignored 控制目录。程序不能因“合成计数为零”绕过旧运行限制。

工程完成、合成功效达标、获准真实研究、发现 Alpha 是四个不同结论。
历史同频可比矩阵未提供时，正式统计保持 NOT_IDENTIFIABLE / null，不填造数值。
本版可以以“工程通过、功效不足、未发现市场 Alpha”诚实验收。
