# V2.7 M0: Formal stop and information firewall

## Objective

Before any new return-driven research, M0 converts the V2.6 failure into irreversible,
replayable governance state. It reads no market data, generates no factor, calls no remote
model and adds no inferential trial.

## Contract

- GitHub Issue #67 is the authority.
- All 48 historical inferential trials remain intact.
- A family-level tombstone covers the flow-confirmation economic mechanism.
- Horizon, threshold, Top-K, residualization, regime and portfolio wrappers cannot escape it.
- A genuinely distinct mechanism is not blocked merely because it uses a shared field.
- 2025 receives an appended `CONSUMED_VALIDATION` state.
- 2026 remains `SEALED_FINAL_TEST`.
- Historical configurations and artifacts are never rewritten.

## Information firewall

Research files are accessible only through an explicit allowlist manifest whose cutoff cannot
exceed 2024-12-31. Logical IDs, paths and hashes must be unique. The interface exposes no
directory enumeration, and unlisted reads are rejected before a file is opened. Public artifacts
retain redacted logical identities and hashes rather than machine-local paths.

## Acceptance

- The rejected candidate and descendants with changed horizons or wrappers return `STOP_FAMILY`.
- A distinct mechanism fixture returns `EXPLORE`.
- Window events and tombstones are append-only.
- 2025/2026 reads, enumerations and hashes remain zero.
- New trials, remote-model requests and live-trading authorization remain zero.
- Bilingual artifacts pass offline SHA-256 replay.
