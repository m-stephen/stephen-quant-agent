# Stephen Quant Agent V2.0 (Shadow Mode)

## Available capability

V2.0 connects hypothesis proposal, safe compilation, cheap deduplication, fast diagnostics, marginal portfolio value, structured failure learning and next-epoch revision or stopping into an auditable loop. It can autonomously complete a budget-constrained engineering research run, but it does not trade live or guarantee profitable alpha.

## Milestones

- M0: lossless V1-to-V2 contracts, hierarchical IDs, Search/Inferential dual ledgers and Replay Manifest.
- M1: allowlisted typed DSL, PIT/static audit, Explore and single-dimension Mutate.
- M2: bounded novelty gate, typed cheap diagnostics and a frozen gate benchmark.
- M3: fold-local residualization and marginal value against a reference portfolio.
- M4: append-only failure graph, frozen epoch policy/budgets and STOP_FAMILY.
- M5: one-command shadow loop, dry-run, kill switch, offline replay and bilingual reports.

## Boundary

V1.8.21 remains a research-only reference. `PROMOTE_FOR_FUTURE_VALIDATION` means only that a candidate deserves future independent validation; it is not Alpha Court approval. Real QD/QMT data, formal CPCV, placebos, DSR/PBO and transaction-cost gates still require a new preregistered experiment.
