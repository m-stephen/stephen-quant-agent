## 判断

早期漂亮结果不能跨时期延续，说明 V8.1 候选更像阶段性流动性效应，而不是稳定 Alpha。
V9.0 的价值是让系统能够发现这种失效并保留证据。后续应消费冻结候选包开展受控、多候选
实证 epoch，并完整保存路径收益矩阵，而不是继续优化这个已失败候选。
