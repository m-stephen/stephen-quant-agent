# V4.7 低换手 Alpha 转换结果

## 结论

V4.7 找到第一个**值得进入前向验证**的开发级候选，但它还不是已证实或可部署的 Alpha。

候选由 `flow_price_divergence_5_20d` 与 `auction_strength_5_20d` 的等权百分位组合构成，
执行时采用 10 档持仓缓冲：已有持仓只有跌入更差的退出区才被替换。相对无缓冲组合，
平均换手从 1.89% 降至 1.13%，降幅约 40%。

| 指标 | 标准成本 | 2 倍成本 |
|---|---:|---:|
| 完整组合超额收益 | +6.96% | +2.36% |
| 完整组合超额夏普 | 1.4784 | 0.5166 |
| 相对匹配对照增量收益 | +12.57% | +13.38% |
| 增量日频夏普 | 2.5939 | 2.7515 |
| 盈利非重叠路径 | 17/20 | 18/20 |
| 路径夏普中位数 / 下四分位 | 0.7111 / 0.5182 | 0.7605 / 0.5488 |
| 最大回撤 | -6.00% | -6.16% |
| 平均换手 | 1.13% | 1.13% |

信号与收益置换检验的经验 p 值均为 0.005，300 万元下未发生容量裁剪。2025 年在标准
成本和 2 倍成本下的增量收益分别为 +1.50% 和 +1.49%，没有出现方向翻转。

## 仍然不能忽略的失败

Alpha Court 结论仍是 `REJECT`。修正后的 DSR 使用 V4.6 的完整 40 个夏普估计与本轮
12 个估计，而不是只使用本轮高度相关的小网格；在累计 1,101 个 Trial 后，DSR 为
`1.68×10⁻⁹`。这说明历史搜索的多重检验负担尚未被独立新样本消化。

2 倍成本下，2023 年完整超额收益仍为 -0.91%，尽管相对匹配对照的增量收益为 +2.48%。
因此候选通过的是“4 年中至少 3 年完整和增量收益同时为正、且 2025 增量为正”的开发
门禁，不代表每个年份都盈利。

## 下一步

停止继续用 2022–2025 调参。从 2026-08-19 起，将信号公式、10 档缓冲、成本模型和
股票池规则冻结后写入 append-only shadow；积累从未参与选择的新样本，再重新计算路径
稳定性、成本压力和 DSR。只有独立前向证据通过 Alpha Court，才能讨论部署。
