# V8.8 最终测试报告

## 结论

按需分钟数据服务已可用。系统可以根据请求自动找到历史总包中的目标股票成员，只解压该成员，
过滤日期、入库并立即从 `qd_minute_current` 查询。精确重放和重叠区间均不会重复写入已有日期。

- source gap：0。

## 风险与边界

1. **高严重度、确定**：历史全市场请求必须显式给股票 allowlist；否则系统拒绝，避免误展开数百 GB。
2. **中严重度、确定**：首次读取历史 ZIP 仍需计算整个归档 SHA-256，真实请求约 25 秒；重放仍会重新
   核验归档身份，但不会重复写入。
3. **中严重度、确定**：当前按需路由覆盖现有 2000–2025 总包及按日归档；源文件内没有的股票或
   日期只会作为 source gap/实际覆盖不足返回。
4. **低严重度、确定**：该能力只解决数据供应，不代表分钟因子已经通过 Alpha Court。
